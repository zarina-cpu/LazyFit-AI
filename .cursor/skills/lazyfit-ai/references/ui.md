# UI LazyFit

Читай этот файл при правках вёрстки, темы или навигации.

## Тема

- Атрибут `html[data-theme="light|dark"]`.
- Ключ `localStorage`: `lazyfit-theme`.
- Инлайн-скрипт в `app/layout.js` ставит тему до гидрации.
- Переменные в `app/globals.css`.
- Кнопки и активный пункт меню: `--fill` / `bg-fill` (#3f6f5c в обеих темах).
- Текст-акцент: `--sage` (в тёмной теме светлее). Не крась белый текст поверх `--sage` в dark.

Шрифты: Manrope (тело), Unbounded (`.display`). Подмножество кириллицы обязательно.

## Адаптив

- Мобильный: липкая шапка + нижнее меню 5 пунктов (Сегодня, План, Импорт, Каталог, Профиль).
- Десктоп (`lg:`): сайдбар 18rem, нижнее меню скрыто.
- Контент: `safe-bottom` = `padding-bottom: calc(5.75rem + env(safe-area-inset-bottom))`.
- Фильтры каталога на узком экране — горизонтальный скролл чипов, не перенос в 3 ряда под шапкой.

## Компоненты

- Оболочка: `components/AppShell.js`
- Карточка: `components/ExerciseCard.js`
- Тема: `ThemeProvider.js` + `ThemeToggle.js` (mounted-guard)
- Отметка подхода: `CompleteButton.js` — после успеха `router.refresh()`, чтобы счётчик на `/today` обновился

Проверка: телефон ~390×844 и десктоп ~1280. Нижняя панель не должна перехватывать клики по кнопкам внизу страницы.
